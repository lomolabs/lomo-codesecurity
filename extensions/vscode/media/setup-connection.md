# One profile, durable membership

1. Open the repository or its workspace parent in your existing VS Code profile.
2. Review **Workspace Trust** through VS Code. Trust is your choice.
3. Use **Connect / Review IDE Access**. Compare the exact request name and verification code when owner approval is needed.

A pristine installation can enroll its first eligible profile through the private installer handoff. Later profiles need approval in **Settings → IDE access**.

**Returning tomorrow:** keep the same backend data, endpoint and editor profile. Reconnect should retain your membership. Never copy credentials between profiles.
